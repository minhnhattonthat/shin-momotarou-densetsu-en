# Style reference (approved pilot: opening, block 237)

## Voices
| Character | Voice |
|---|---|
| Karura | sly, sneering courtier; cackles "Keeh, keh-keh-keh!"; flatters Basara ("sire") |
| King Basara | regal, terse, formal ("Enough, Karura!", "Very well!") |
| King Enma | gruff but honourable oni ex-king |
| Villagers | folksy, rustic dialect ("Ain't that Momotaro?", "ya", "gotta") |
| Narration | plain storybook past/present tense |

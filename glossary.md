# Glossary - Shin Momotarou Densetsu (SNES, Hudson Soft 1993)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (pre-approved by the user, 2026-10-16)
- Honorifics: dropped, conveyed through register (さん/様/殿 -> nothing, "Lord", "Lady", "sir" only where the
  Japanese is clearly a title). Name order: given name first.
- Romanisation: official English where it exists (none for this game), else modified Hepburn without macrons
  (Momotaro, Kintaro, Onigashima, Ryugu).
- Credits: English. Text drawn as graphics: in scope.
- Full names and terms, no abbreviations. Engine work before cutting meaning; abbreviate only as a flagged last
  resort (report `LONG:`).
- Register: a light, comic folk-tale RPG for all ages (Sakuma Akira). Keep the jokes, puns and parody; adapt
  wordplay so it still lands. Villagers may speak in rustic dialect ("ain't", "ya"), oni boast, sages are pompous.
- Sound effects / laughs: romanised and expressive (Karura's ケーケッケッ -> "Keeh, keh-keh-keh!").

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', ・・・/… -> ..., ！？ -> !?, ～ -> ~, ー (long vowel in shouts) -> repeat
  the vowel ("Kintaaaan!"). Only ASCII; `...` for ellipses.
- Japanese furigana in parentheses (伐折羅(ばさら)王) is a reading aid: translate the name once, drop the reading.
- Speaker lines: `{c1}Name{n}{c0}"Line"` exactly as the Japanese structure.
- `{sub:XX}` codes are a compression dictionary (e.g. {sub:A0} = 桃太郎 = Momotaro, {sub:C5} = ください = please).
  Never keep them: write the words out.
- `{hero}` = the hero's name (Momotaro). `{arg}` = a name/item/number the game inserts; `{num}` = a number.
  Keep each exactly once per occurrence in the Japanese; no "a/an" right before them, no suffix glued on them.
- Money: 両 -> ryo ("100 ryo").
